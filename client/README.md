# Envoy Client

Multiplatform client HTTP/networking library built on the [Envoy](https://www.envoyproxy.io) project's core networking layer.

## Documentation

- **[Official documentation](https://envoyclient.io/docs/envoy-client/latest/index.html)**
- [Project website](https://envoyclient.io)
- [Getting started demos](https://envoyclient.io/docs/envoy-client/latest/start/start.html)
- [API and usage](https://envoyclient.io/docs/envoy-client/latest/api/api.html)
- [Additional resources](https://envoyclient.io/docs/envoy-client/latest/intro/additional_resources.html)

## Contact

* [envoy-client-announce](https://groups.google.com/forum/#!forum/envoy-client-announce): Low
  frequency mailing list where we will email announcements only.
* [envoy-client-users](https://groups.google.com/forum/#!forum/envoy-client-users): General user
  discussion.
* [envoy-client-dev](https://groups.google.com/forum/#!forum/envoy-client-dev): Envoy Client
  developer discussion (APIs, feature design, etc.).
* [Slack](https://envoyproxy.slack.com): Slack, to get invited go
  [here](https://envoyproxy.io/slack). We can be found in the **#envoy-client** room.
